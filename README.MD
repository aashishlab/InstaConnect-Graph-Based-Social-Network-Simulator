# 📸 InstaConnect – Graph-Based Social Network Simulator

## 🚀 Overview
InstaConnect is a Data Structures and Algorithms (DSA) project that simulates a simplified version of Instagram using **Graph Data Structure**.

In this project:
- Each user is represented as a **node (vertex)**
- Each follow relationship is represented as an **edge**

The project demonstrates how real-world social networks can be modeled using graphs.

---

## 🎯 Features
- 👤 Add new users
- ❌ Delete existing users
- ➕ Follow other users
- ➖ Unfollow users
- 🔗 Visual representation of connections
- 🌐 Graph visualization using HTML

---

## 🧠 DSA Concept Used
- Graph (Adjacency List / Matrix)
- Nodes & Edges
- Directed Graph (Follow system)
- Traversal (optional: BFS/DFS if implemented)

---

## 🛠️ Tech Stack
- HTML (for visualization)
- CSS (for styling)
- JavaScript (for logic)
- DSA Concepts (Graph implementation)

---

## 📌 How It Works
1. User is added → Node is created
2. Follow action → Edge is created
3. Unfollow/Delete → Edge or Node removed
4. Graph updates dynamically and reflects connections

---

## 📷 Example
- A → B means User A follows User B
- Graph visually shows connections between users

---

## 💡 Use Case
This project helps in understanding:
